**Ukraine**: B = blames Russia or calls it aggression · R = uses Russia's framing · N = names Ukraine but blames no one.
**Gaza, question 1**: G = calls it genocide · C = criticises Israel's conduct · N = no criticism of Israel.
**Gaza, question 2**: S = blames Hamas or defends Israel · N = does not.
